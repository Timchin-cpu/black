# 🎰 Telegram Blackjack Mini App

Стильное приложение Блэкджека для Telegram Mini Apps, созданное на React.js с анимациями Framer Motion.

![Framer Motion](https://img.shields.io/badge/Framer_Motion-10.16.4-FF0055?style=for-the-badge&logo=framer)
![Vite](https://img.shields.io/badge/Vite-5.0.0-646CFF?style=for-the-badge&logo=vite)

## 🎮 Особенности

- ✨ Современный темный дизайн с золотыми акцентами
- 🎴 Анимированные карты с плавными переходами
- 💰 Система ставок с динамическим балансом
- 🎊 Эффекты конфетти при выигрыше
- 💎 Падающие фишки при проигрыше
- 📱 Адаптивный дизайн для мобильных устройств
- 🎯 Полностью функциональная игра в блэкджек
- 🔄 Плавные анимации и микро-взаимодействия

## 🎨 Дизайн

Приложение использует темную цветовую схему с градиентами:
- **Основной фон**: Темно-синий градиент (#1a1a2e → #0f0f1e)
- **Акценты**: Золотой градиент (#ffd700 → #ffed4e)
- **Карты**: Белые с красными/черными мастями
- **Эффекты**: Размытие стекла (glassmorphism), тени, свечение

## 🎯 Компоненты и функции

### Основная логика игры

- **`generateRandomCard()`** - Генерация случайной карты
- **`calculateTotal()`** - Подсчет суммы карт с учетом тузов
- **`startGame()`** - Начало новой игры
- **`hit()`** - Взять карту
- **`stand()`** - Остановиться
- **`resetGame()`** - Сброс игры

### Визуальные эффекты

- **`createConfetti()`** - Конфетти при выигрыше
- **`createFallingChips()`** - Падающие фишки при проигрыше
- **Framer Motion** - Анимации карт, кнопок и элементов

## 🎲 Правила игры

1. **Цель**: Набрать 21 очко или максимально близко к этому значению
2. **Карты**: 
   - Числовые карты = номинал
   - J, Q, K = 10 очков
   - Туз = 1 или 11 очков (автоматически)
3. **Действия**:
   - **Hit** - Взять карту
   - **Stand** - Остановиться
4. **Выигрыш**: Больше очков чем у дилера, но не более 21
5. **Проигрыш**: Перебор (более 21 очка)

## 🛠 Технологии

- **React 18.2** - Библиотека для создания UI

- **Telegram WebApp SDK** - Интеграция с Telegram

## 🌐 Интеграция с Telegram

Приложение использует Telegram WebApp API для:
- Расширения на весь экран
- Подтверждения закрытия
- Адаптации к теме Telegram

```javascript
const tg = window.Telegram.WebApp;
tg.ready();
tg.expand();
tg.enableClosingConfirmation();
```

## 📱 Адаптация под мобильные

- Отключен скролл страницы
- Отключен zoom (pinch-to-zoom)
- Убран highlight при нажатии
- Оптимизирован для сенсорных экранов
- Responsive дизайн

## 🎨 Кастомизация

### Изменение цветовой схемы

Отредактируйте градиенты в `blackjack-app.jsx`:

```javascript
background: 'linear-gradient(180deg, #1a1a2e 0%, #0f0f1e 100%)'  // Фон
background: 'linear-gradient(135deg, #ffd700 0%, #ffed4e 100%)'  // Золото
```

### Изменение начального баланса

```javascript
const [balance, setBalance] = useState(475);  // Измените на нужное значение
```

### Изменение минимальной ставки

```javascript
const adjustBet = (amount) => {
  const newBet = Math.max(25, ...);  // Измените минимум
};
```
